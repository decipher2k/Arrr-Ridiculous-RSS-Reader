Arrr – Advanced Robot RSS Reader

Ein moderner, plattformübergreifender Desktop-RSS-Reader mit KI-gestützter Deduplizierung, Übersetzung und Zusammenfassung. Lokale KI direkt integriert – kein Ollama, kein Docker, kein Setup.

Read smarter. Stay informed. Own your data.

🖥️ Windows · macOS · Linux 🧠 Lokale KI (llama.cpp) ☁️ OpenAI-kompatibel 🌐 9 Sprachen 📄 Apache 2.0
🚀 Loslegen ✨ Features entdecken

Core Features

Alles, was ein moderner RSS-Reader braucht – und mehr.

📰

News-ähnliches Layout

Drei-Panel-Zeitungslayout mit bildreichen Artikelkarten. Keine langweilige Listenansicht – fühlt sich an wie eine moderne Nachrichtenseite.

🧠

KI-Deduplizierung

Erkennt semantisch identische Artikel über verschiedene Quellen hinweg. Gleiche Nachricht von 5 Portalen? Nur einmal angezeigt – der Rest wird gruppiert.

🌍

KI-Übersetzung & Zusammenfassung

Übersetze Artikel in 9 Sprachen (DE, EN, FR, ES, IT, HI, ZH, RU, JA). Auf ~500 Wörter zusammengefasst. Ein Klick zwischen Original und Übersetzung.

💻

Lokale KI – Kein Setup

llama.cpp + Ministral-3B direkt eingebaut. Modell-Download per Knopfdruck. Kein Ollama, kein Docker, keine Kommandozeile nötig.

☁️

OpenAI-Kompatible API

Nutze OpenAI, Azure, LiteLLM oder jeden anderen OpenAI-kompatiblen Endpunkt. API-Key wird verschlüsselt im Betriebssystem-Schlüsselbund gespeichert.

📡

Artikel-Scraping

Extrahiere den vollständigen Artikel-Inhalt von der Quellwebseite – nicht nur den RSS-Teaser. Pro Feed konfigurierbar: Feed-Inhalt oder Originalartikel.

Schnellstart in 3 Schritten

In wenigen Minuten von Null auf produktiv.

1

App herunterladen & starten

Lade die passende Version für dein Betriebssystem herunter (Windows .exe, macOS .dmg, Linux .AppImage/.deb). Installieren, starten – fertig.

2

Feeds hinzufügen & Kategorien anlegen

Lege Kategorien wie „Technik", „Politik" oder „Wissenschaft" an. Füge RSS/Atom-Feed-URLs hinzu. Ein Klick auf „Abrufen" holt die neuesten Artikel.

3

KI konfigurieren (optional)

Wähle zwischen lokalem Modell (Download per Knopfdruck) oder OpenAI-kompatibler API. Aktiviere Deduplizierung und/oder Übersetzung nach Bedarf.
