Installation

Arrr läuft auf Windows, macOS und Linux. Wähle die für dich passende Methode.

🛠️ Selbst kompilieren

Voraussetzungen: Node.js ≥ 18 und npm ≥ 9.

1. Repository klonen

git clone https://github.com/example/rss-reader-electron.git
cd rss-reader-electron

2. Abhängigkeiten installieren

npm install
Hinweis: Der postinstall-Hook führt electron-builder install-app-deps aus, um native Module (SQLite) für Electron zu kompilieren.

3. Bauen & starten

npm run build      # Produktions-Build
npm run electron   # App starten

4. Entwicklungsmodus

npm run dev            # Vite Dev-Server (Renderer auf Port 5173)
npm run electron:dev   # Main-Prozess bauen + Electron starten
Entwicklungsmodus: Der Renderer läuft auf http://localhost:5173 mit Hot Module Replacement. Der Electron Main-Prozess verbindet sich automatisch mit dem Vite Dev-Server.

📁 Projektstruktur

src/
├── main/              # Electron Main Process
│   ├── main.ts        # App-Einstieg, Fenster, Auto-Fetch
│   ├── preload.ts     # Context Bridge (electronAPI)
│   ├── ipc.ts         # IPC-Handler (Datenbank, Feeds, KI)
│   ├── db/            # SQLite-Datenbank (6 Tabellen)
│   ├── ai/            # KI-Provider & Features
│   ├── feeds/         # RSS-Parsing, Bildextraktion
│   ├── articles/      # Artikel-Scraping & Extraktion
│   └── settings/      # Verschlüsselte Einstellungen
├── renderer/          # React Frontend
│   ├── App.tsx        # Wurzel-Layout
│   ├── components/    # UI-Komponenten
│   ├── state/         # Zustand Store
│   └── i18n/          # 9 Sprachdateien
├── shared/            # Typen, Konstanten, Validierung
└── resources/
    └── llama.cpp/     # Gebundelte llama.cpp-Binaries
