Einrichtung

Schritt-für-Schritt: Vom ersten Start zur produktiven Nutzung.

📋 Erster Start

Nach dem ersten Start siehst du die leere Oberfläche mit der Kategorie-Leiste oben und dem leeren Artikelbereich. Über den Button „Verwalten" gelangst du in den Feed-Manager.

1. Kategorien anlegen

Kategorien helfen, deine Feeds zu organisieren. In der oberen Leiste:

  1. Klick auf das „+"-Feld links in der Kategorie-Leiste
  2. Name eingeben (z.B. „Technik", „News", „Wissenschaft")
  3. Mit Enter oder Klick auf „Hinzufügen" bestätigen

Kategorien lassen sich per Rechtsklick umbenennen, löschen oder in der Reihenfolge verschieben.

2. Feeds hinzufügen

Öffne den Feed-Manager über den „Verwalten"-Button:

  1. Titel für den Feed vergeben (wird automatisch aus dem RSS-Feed übernommen)
  2. RSS/Atom-URL eingeben (z.B. https://heise.de/security/rss/news-atom.xml)
  3. Kategorien auswählen (Mehrfachauswahl möglich)
  4. Detailansicht wählen:
    • Feed-Inhalt: Zeigt den RSS-Text an (schnell, weniger Inhalt)
    • Verlinkte News: Scraped den vollständigen Artikel von der Webseite (mehr Inhalt, langsamer)
  5. Klick auf „Hinzufügen"

Wiederhole diesen Schritt für alle gewünschten Feeds.

⚙️ KI-Provider konfigurieren

Öffne die Einstellungen über den „Einstellungen"-Button (Zahnrad-Icon).

Option A: OpenAI-kompatible API (extern)

  1. Wähle „OpenAI-kompatibel (extern)" als KI-Anbieter
  2. Gib die API Base URL ein (Standard: https://api.openai.com/v1)
  3. Gib deinen API Key ein (wird verschlüsselt im OS-Schlüsselbund gespeichert)
  4. Wähle das Modell (z.B. gpt-4o-mini, gpt-4o)
  5. Passe die Temperatur an (Standard: 0.2, niedrig für präzise Ergebnisse)
  6. Klick auf „Verbindung testen" zur Überprüfung
Kompatibel mit: OpenAI, Azure OpenAI, LiteLLM, OpenRouter, lokale llama-server-Instanzen und allen anderen Diensten mit OpenAI-kompatibler /chat/completions-Schnittstelle.

Option B: Lokales Modell (llama.cpp)

  1. Wähle „Lokales Modell (llama.cpp)" als KI-Anbieter
  2. Klick auf „Modell herunterladen" – das Ministral-3-3B-Instruct-Modell (~1,9 GB) wird von HuggingFace geladen. Der Download-Fortschritt wird in Echtzeit angezeigt.
  3. Nach dem Download ist das Modell sofort einsatzbereit. Die App startet llama-server automatisch im Hintergrund.
  4. Passe bei Bedarf an:
    • Server-Port: Standard 8080
    • Kontextgröße: Standard 8192 Tokens
    • GPU-Layer: Standard 99 (alle auf GPU)
    • CPU-Fallback: Erlauben, wenn keine GPU verfügbar (deutlich langsamer)
  5. Klick auf „Lokale Verbindung testen"
Systemanforderung lokale KI: Das Modell benötigt ca. 4–5 GB VRAM. Eine CUDA-fähige NVIDIA-GPU wird empfohlen. Ohne GPU (CPU-Fallback) ist die Verarbeitung ca. 10–20× langsamer.

⏱️ Automatischen Abruf aktivieren

Aktiviere „Automatischen Feed-Abruf aktivieren" und stelle das gewünschte Intervall ein (5–1440 Minuten). Die App holt dann selbstständig neue Artikel im Hintergrund – auch wenn das Fenster minimiert ist.

Nach der Einrichtung kannst du:

  • KI-Deduplizierung und Übersetzung aktivieren
