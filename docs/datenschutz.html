3. Datenerhebung und -speicherung

3.1 Lokale Datenspeicherung

Der Arrr RSS Reader speichert folgende Daten ausschließlich lokal auf Ihrem Gerät:

  • Konfigurierte RSS/Atom-Feed-URLs
  • Abgerufene Artikel-Inhalte (Texte, Bilder)
  • Kategorie-Namen und -Struktur
  • Nutzer-Einstellungen (Sprache, KI-Konfiguration)
  • KI-Übersetzungen (Cache)
  • KI-Deduplizierungsergebnisse

Diese Daten werden in einer SQLite-Datenbank sowie einer JSON-Konfigurationsdatei im Benutzerdatenverzeichnis Ihres Betriebssystems gespeichert:

  • Windows: %APPDATA%/rss-reader-electron/
  • macOS: ~/Library/Application Support/rss-reader-electron/
  • Linux: ~/.config/rss-reader-electron/

3.2 API-Keys

Bei Nutzung eines externen KI-Providers wird Ihr API-Key mit der Betriebssystem-eigenen Verschlüsselung gesichert:

  • macOS: Keychain
  • Windows: DPAPI (Data Protection API)
  • Linux: libsecret / Kernel Keyring

Der API-Key wird zu keinem Zeitpunkt im Klartext auf der Festplatte gespeichert und nie an Dritte weitergegeben.

4. Keine Übermittlung an Dritte

Der Arrr RSS Reader überträgt keine personenbezogenen Daten an den Entwickler oder an Dritte. Es gibt:

  • Keine Telemetrie oder Nutzungsanalyse
  • Keine Crash-Reports (außer Sie leiten diese manuell weiter)
  • Keine Werbung oder Tracking-Codes
  • Keine Cloud-Synchronisation

5. Externe Dienste – was das Programm tut

5.1 RSS/Atom-Feeds

Die App ruft RSS/Atom-Feeds von den von Ihnen konfigurierten URLs ab. Dabei wird Ihre IP-Adresse an den jeweiligen Feed-Anbieter übermittelt – wie bei jedem RSS-Reader. Dies ist technisch notwendig, um die Artikel zu laden.

5.2 Artikel-Scraping

Wenn für einen Feed der Modus „Verlinkte News" (Scraping) aktiviert ist, ruft die App zusätzlich die verlinkte Artikelseite ab, um den vollständigen Inhalt zu extrahieren. Auch hierbei wird Ihre IP-Adresse an den jeweiligen Webseiten-Betreiber übermittelt.

5.3 KI-Anbieter (optional)

Wenn Sie einen externen KI-Provider (OpenAI-kompatible API) konfigurieren, werden Artikeltexte zur Verarbeitung (Deduplizierung, Übersetzung) an die von Ihnen angegebene API-URL gesendet. Welche Daten dabei übertragen werden, liegt in Ihrer Verantwortung und hängt vom jeweiligen Anbieter ab.

Empfehlung: Bei Nutzung des lokalen Modells (llama.cpp) werden keine Daten an externe Server gesendet. Die gesamte KI-Verarbeitung findet auf Ihrem Rechner statt.

5.4 Modell-Download

Bei Nutzung des lokalen KI-Modells lädt die App das Modell (Ministral-3-3B-Instruct) von HuggingFace-Servern herunter. Dies ist ein einmaliger Download. Ihre IP-Adresse wird dabei an HuggingFace übermittelt.
